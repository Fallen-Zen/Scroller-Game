---
description: Build and run the game
---

Build and launch the Scroller game.

1. Build first (same as /build). Stop if build fails.

2. Run the executable:
   - macOS: `./build/Scroller` (or open the .app bundle if it exists)
   - Linux: `./build/Scroller`
   - Windows: `build\Debug\Scroller.exe`

3. The game window will open. Controls:
   - Arrow keys or WASD: move
   - Space / W / Up: jump
   - Escape: quit

4. Report any runtime errors (segfault, SDL error dialog) and help diagnose them.
